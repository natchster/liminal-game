# The props remodelled: the notes of each family

How each family of props was made finer in Blender: per placer, what was
rebuilt, what was left and why, the sources and sizes of the real things,
the placement problems seen. They are the record of that work, kept as
written; the families' sources are in `assets/src/blender/props/<theme>/`
(its README is the modelling contract and the index). The notes name the
batch each family was made in (*was*), as the commits of the time do.
